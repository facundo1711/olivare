# OLIVARÉ — sitio web académico

Sitio demostrativo responsive para la marca ficticia OLIVARÉ, de San Juan, Argentina.

## Páginas
- `index.html`: Inicio
- `productos.html`: catálogo de productos con filtros
- `nosotros.html`: historia y valores de marca
- `contacto.html`: formulario con validación de navegador
- `recetas.html`: tarjetas de recetas con filtros
- `packs.html`: packs y regalos

## Tecnologías
HTML5, CSS3, Bootstrap 5.3.3, Bootstrap Icons y JavaScript vanilla.

## Cómo abrir
Abrí `index.html` en un navegador. Se usan recursos CDN y fotografías externas, por lo que se necesita conexión a internet para ver tipografías, Bootstrap e imágenes.

## Antes de publicar
- Reemplazar los datos de contacto ilustrativos por datos autorizados.
- Confirmar los textos y el catálogo real.
- Conectar formularios a un servicio/backend si se desea recibir mensajes.
- Revisar licencias y disponibilidad de las imágenes usadas.
- Probar todas las páginas en PC y móvil.

Los productos, nombres de packs y textos son demostrativos; no representan una tienda real ni procesan compras.


## Imágenes de productos
Se ajustaron las imágenes del catálogo para que correspondan visualmente con aceite de oliva, aceitunas y conservas. Son imágenes ilustrativas de referencia, no fotografías de productos OLIVARÉ propios; conviene sustituirlas por fotografías autorizadas o imágenes de marca antes de publicar.

## Actualización visual de OLIVARÉ
Las fotografías principales de aceite, aceitunas, conservas y packs ahora están guardadas localmente en `assets/`, para que no dependan de enlaces externos. La página de inicio incorpora una presentación editorial de packs y regalos inspirada en la referencia visual acordada. Las imágenes son recursos de maqueta generados para el proyecto académico ficticio.
